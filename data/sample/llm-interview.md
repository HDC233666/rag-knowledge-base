# 大模型应用开发面试常考问题（示例文档）

## 一、RAG 和微调有什么区别？

RAG 是「外挂知识」：把资料检索出来放进上下文，模型本身不变，改知识只需换文档。
微调是「改模型参数」：告诉模型新的行为或风格，成本高、周期长、容易遗忘旧知识。
实际项目里：知识频繁更新用 RAG，说话风格/固定格式用微调，两者可以结合。

## 二、function calling 是什么？

function calling（工具调用）是让大模型输出「我要调用哪个函数、参数是什么」的结构化 JSON。
程序收到后执行真实函数，把结果再交给模型，模型继续推理，直到给出最终答案。
它是 Agent 的基础：模型负责决策，代码负责执行。

## 三、Agent 和普通对话机器人有什么区别？

普通对话机器人一问一答。
Agent 有目标、能多步行动：观察环境、调用工具、根据结果调整计划，直到完成任务。
核心组成：大模型（大脑）+ 工具（手脚）+ 循环（多步执行）+ 记忆（上下文）。

## 四、提示词工程有哪些常用技巧？

- 明确角色和任务边界；
- 给例子（few-shot）；
- 要求分步骤思考；
- 指定输出格式（JSON、Markdown）；
- 要求引用来源、拒绝编造；
- 把长提示词拆成系统提示词 + 用户输入。

## 五、怎么防止大模型胡说八道？

- 提供可靠上下文（RAG），要求只依据资料回答；
- 让模型标注出处，便于人工核对；
- 设置兜底回答：「资料中没有相关内容」；
- 对高风险场景加人工审核；
- 用规则或另一个模型做校验。

## 六、FastAPI 是什么？

FastAPI 是 Python 的 Web 框架，用来快速写 HTTP 接口。
特点：基于类型提示自动校验参数、自动生成接口文档（/docs）、异步支持好、性能接近 Node.js。
本类项目典型用法：定义 Pydantic 模型描述请求体，写 @app.get / @app.post 路由。

## 七、为什么要做文本切分？chunk 大小怎么定？

切分是为了让检索更精准，也让上下文不超限。
块大小没有标准答案：中文一般 200-800 字，重叠 10%-20%。
最佳做法是拿真实问题做实验，比较不同切分的召回率和回答质量。
