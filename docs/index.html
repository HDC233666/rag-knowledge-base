做了什么

  • 检索链路：文档按段落切块（600 字 / 80 字重叠）→ BM25 + bge-small-zh 向量双路召回 → RRF 融合（k=60）→ LLM 查询改写 → LLM 重排 → Top-N 拼装 Prompt。
  • 数据层：MySQL 两表（documents / chunks，外键级联删除 + 索引加速），数据库不可用时自动降级 JSON，保证演示环境可用；FAISS HNSW 索引，环境不支持时降级 numpy 暴力检索。
  • 工程与安全：SSE 分阶段流式（stage / delta / done）、按 IP 限流、prompt 注入识别与中和、系统提示泄露兜底、服务端多轮会话（TTL + 轮数上限）。
  • 可观测与评估：token 与费用估算、延迟 P50/P95、缓存命中率看板；一条命令跑 100 题 × 4 组检索配置 + 生成质量（LLM-as-judge）+ RAGAS 四指标。
